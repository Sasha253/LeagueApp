# Design

- `src/ds/`: the League App design system, copied unchanged from
  `League App Design System.zip` (2026-10-20): README, Screens, tokens and the component CSS.
- `key-moments-draft.html`: the five key moments from Screens.md, 25 artboards at 375 × 812.
  Open it in a browser; zoom buttons are top right.
- `src/`: the generator that builds the canvas. `node design/src/build.mjs draft` rebuilds it.
  Screens live in `src/screens/`, proposed components in `src/proposed.css`.
